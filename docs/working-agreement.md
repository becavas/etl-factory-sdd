# Acuerdo de trabajo

- Cada cambio después del arranque se integra mediante una PR desde una rama corta.
- main conserva el estado integrado; DEV, CERTI y PROD no son ramas Git.
- Se revisa el diff antes del merge y se declara quién revisó.
- Los checkpoints no se mueven ni se reutilizan para otro commit.
- No se versionan credenciales, hosts, IDs reales, fichas ni bitácoras.
- La IA solo explica en M01 y no escribe ni ejecuta por el alumno.
- La administración propia y la self-review se declaran como tales.
