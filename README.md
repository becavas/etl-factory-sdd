# etl-factory-sdd

Fábrica de ETL de práctica. El código y los controles se incorporan por módulos.

El entorno Python se declara en environment.yml y Node en .nvmrc.
Las instrucciones de preparación y versiones son las de M01 del material del curso.
La bitácora y la ficha de plataforma se guardan fuera del repositorio.

## Preparación del entorno

```bash
make env
conda activate etl-factory-sdd
nvm use
make doctor
```
